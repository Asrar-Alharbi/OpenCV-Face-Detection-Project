# Real-Time Face Detection & Recognition using OpenCV 🎭

A Python-based Computer Vision project that performs real-time face detection and recognition using **OpenCV** and the **Haar Cascade Classifier**. The application captures live video feed from the system's webcam, processes frames to detect human faces, and displays bounding boxes around detected faces in real time.

---

## 📌 Project Overview
This project fulfills the Computer Vision assignment task by implementing real-time face recognition. It leverages OpenCV's pre-trained Haar Cascade XML model (`haarcascade_frontalface_default.xml`) to identify facial features efficiently with minimal processing overhead.

---

## 🛠️ Features
* **Real-Time Video Processing:** Captures live feed directly from the webcam.
* **Accurate Detection:** Uses Haar Cascades to locate human faces across varying frame angles.
* **Visual Bounding Box:** Draws rectangles and labels (`Face Detected`) around identified face regions.
* **Smooth Exit Control:** Allows graceful termination of the webcam stream by pressing the `'q'` key.
